# 配图卡（配图者开工前读这一张就够）

## 步骤
1. 粗筛：`python -P 根\tools\frames.py sheet video.mp4 sheets --start 0 --end <时长> --step 30`，看全片缩略图拼板。
2. 精筛：只在候选时间点附近用 `--step 3` 出局部拼板，确认最佳时刻。
3. 写 `配图计划.json`，每项：`seconds, file, chapter, anchor, before, alt, caption, reason, visual_check`。
   - `caption` 以"（原视频 HH:MM:SS）"结尾
   - `anchor` 是正文里的一段原文，用来定位插图位置。正文还没定稿时先留空，并在 `reason` 里写清这张图配哪段内容，由主对话在定稿后补上
4. 取图：`python -P 根\tools\frames.py grab video.mp4 配图计划.json 根\<slug>_访谈长文_assets`
5. 逐张打开取出的原图核对，结果写进 `visual_check`。对不上就换时间点重取。

## 选图规则
- 一般 8–15 张；短片段按内容取，大约每 1–2 分钟一张，宁缺毋滥。
- 开场全景 1 张，尽量让主持人和嘉宾同框。全片都没有同框画面（多机位剪辑、视频连线、单机位）时，用最能交代现场的单人镜头，图注里交代采访形式。
- 节目当场展示的屏幕材料优先：推文、图表、照片、地图、新闻画面。同一事件有多个画面，选最能体现事件分量的那张。
- 受访者特写最多 3 张，必须对应关键论述或情绪高点；谈沉重话题时，表情也要对得上。
- 不选闭眼、转场、模糊的画面；附近有片尾订阅卡、转场时要确认没取错帧。
- 不凭表情推断心理。图注写的内容，画面上必须真有（以往"颁勋章"的图里根本没在颁奖）。
