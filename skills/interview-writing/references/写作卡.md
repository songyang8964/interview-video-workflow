# 访谈长文写作卡（每章开写前、润色前重读）

## 底线（违反任何一条都要返工）
1. **完整**：本章素材包里的每个信息点都要写到；讨论超过 30 秒的话题必须有对应段落。尖锐、争议的段落一个都不能跳过。
2. **忠实**：数字、人名、年份、限定词（"可能""大约""我认为"）照原样保留；不替受访者补论据，不软化也不强化他的表态。
3. **让步与限定同样保留**：受访者的"我承认……""公平地说……"和自我修正，与他最尖锐的话一样重要。删掉这些会让他显得更极端，这也是偏向。
4. **不站队**：双方用对等的动词（都用"认为/指出/表示"）；编者注只补背景（人物、事件、制度），不做价值判断，也**不能紧跟在受访者的观点后面起反驳作用**；反驳性核查一律放文末附注。
5. **不编造**：神态、动作、停顿、"第一次公开"之类的说法，逐字稿或画面里没有依据就不写；转场提问必须是原话。
6. **中文为主**：对话全部改写成中文；每章 1–2 条双语金句（中文在前，英文在后，用引用块）。
7. **译名统一**：人名、机构、术语一律按本期 `译名表.md` 翻译；英文原名只在全文首次出现时括注。
8. **正文不谈整理过程**：不写"字幕""逐字稿""本文"；原话不完整时，按上下文意译，说明放到文末附注。

## 写法
9. **先懂后写**：先读完这一段英文，想清楚"他到底在说什么"，再合上英文用中文讲出来。不逐句对译。
10. **一句一事**：超过 60 字就拆；长定语拆出去单独成句；破折号每千字不超过 4 个。
11. **具体主语**：用人和动作做主语（"罗根追问""他举了个例子"），少用"问题""这一点""叙事框架"。
12. **转述为主**：直接引语只给最有性格的话，一段最多两处，每处最多两句。
13. **口语对口语**：俚语找中文的对应说法；典故意译，必要时加编者注。引语里的"你知道""说实话""就是这样""对吧"大多删掉；"为什么？因为……"一章最多留一处。
14. **问答感**：保留关键追问、打断、改口和分歧，写清楚是谁问的、谁答的。
15. **独白按步骤展开**：长独白按论证步骤写成几段，不压成一句概括。
16. **人要交代**：每个人第一次出场时交代身份，例如"罗根的制作人杰米"。离题的段落要交代它和访谈主线是什么关系。
17. **衔接靠内容**：用"说到这里""罗根不同意"这类内容衔接，不用"此外""与此同时""值得注意的是"。

## 禁用（lint_zh.py 会查）
众所周知 / 值得注意的是 / 不得不说 / 综上所述 / 总之 / 让我们拭目以待 / 赋能 / 闭环 / 发人深省 / 定海神针 / 不十分清晰 / 逻辑关联不紧密 / 万能钥匙 / 利用平台 / 嘴硬 / 进行+动词 / 被……所 / 作为一个 / 字幕 / 逐字稿

## 写完本章自查（四问）
- 把本章念一遍：有没有哪句听着像翻译？改掉。
- 对照素材包：有没有信息点没写到？受访者的让步和限定还在吗？
- 有没有哪句是我在评价受访者，而不是转述他？删掉，或移到文末附注。
- 有没有哪个动作、神态、转场提问是我想象出来的？删掉。
