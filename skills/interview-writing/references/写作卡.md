# 访谈长文写作卡（每章开写前、润色前重读）

## 底线（违反任何一条都要返工）
1. **完整**：本章素材包里的每个信息点都要写到；讨论超过 30 秒的话题必须有对应段落。尖锐、争议的段落一个都不能跳过。
2. **忠实**：数字、人名、年份、限定词（"可能""大约""我认为"）照原样保留；不替受访者补论据，不软化也不强化他的表态。
3. **不站队**：双方用对等的动词（都用"认为/指出/表示"）；编者注只补背景（人物、事件、制度），不做价值判断；事实核查放到文末附注。
4. **中文为主**：对话全部改写成中文；每章最多 1–2 条双语金句（中文在前，英文在后，用引用块）。

## 写法
5. **先懂后写**：先读完这一段英文，想清楚"他到底在说什么"，再合上英文用中文讲出来。不逐句对译。
6. **一句一事**：超过 60 字就拆；长定语拆出去单独成句；少用破折号插入语。
7. **具体主语**：用人和动作做主语（"罗根追问""他举了个例子"），少用"问题""这一点""这种现象"。
8. **转述为主**：直接引语只给最有性格的话，一段最多两处，每处最多两句。
9. **口语对口语**：俚语找中文的对应说法；典故意译，必要时加编者注。
10. **问答感**：保留关键追问、打断、改口和分歧，写清楚是谁问的、谁答的。
11. **衔接靠内容**：用"说到这里""罗根不同意"这类内容衔接，不用"此外""与此同时""值得注意的是"。

## 禁用（lint_zh.py 会查）
众所周知 / 值得注意的是 / 不得不说 / 综上所述 / 总之 / 让我们拭目以待 / 赋能 / 闭环 / 发人深省 / 不十分清晰 / 逻辑关联不紧密 / 进行+动词 / 被……所 / 作为一个

## 写完本章自查（三问）
- 把本章念一遍：有没有哪句听着像翻译？改掉。
- 对照素材包：有没有信息点没写到？补上。
- 有没有哪句是我在评价受访者，而不是转述他？删掉，或移到文末附注。
