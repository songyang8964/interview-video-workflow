# 翻译腔对照表

润色时按"英文结构 → 直译 → 自然中文"对照检查。示例部分取自本项目历次修订记录（Peterson、Rupert Lowe 等）。

## 句法结构

| 英文结构 | ❌ 直译 | ✅ 自然中文 |
|---|---|---|
| 长定语从句 the people who are in power and who are responsible for… | 那些拥有权力并且对这些政策负有责任的人 | 掌权的人推行了这些政策 |
| 插入语 X — which was… — did Y | 温德拉什一代——来自加勒比的移民——填补了…… | 最早来的是"温德拉什一代"，也就是从加勒比来的移民。他们…… |
| 名词化 his determination to turn it into a conflict | 她要把它变成冲突的决心 | 她一心要把采访变成一场冲突 |
| 被动语态 he was attacked by the media | 他被媒体所攻击 | 媒体围攻他 / 他遭到媒体围攻 |
| as a … | 作为一个父亲，他…… | 他有女儿，所以…… / 身为父亲，他…… |
| in terms of … | 在经济方面，…… | 经济上，…… / 直接删 |
| when … | 当他回到家的时候 | 他回到家时 / 一回家 |
| make sb feel … | 这让他感到非常愤怒 | 他气坏了 |
| that's why … | 这就是为什么他离开了 | 所以他走了 |
| it's a … thing | 这是一个关于信任的问题 | 说到底是信任 |
| there is / there are | 存在着一种倾向 | 人们往往…… |
| the fact that … | 他住在伦敦的这一事实 | 他住在伦敦 |
| one of the most … | 最重要的问题之一 | 一个大问题 / 头等大事 |
| 抽象名词主语 the question came down to a person | 问题落到了一个人身上 | 话题转向一个人该怎样活 |
| 多重修饰 | 一个深刻的、复杂的、长期存在的历史问题 | 一个老问题，牵扯很多 |

## 动词和搭配

| ❌ | ✅ |
|---|---|
| 进行了讨论 / 进行分析 | 讨论了 / 分析 |

| 起到了重要的作用 | 很关键 / 说明作用是什么 |
| 拆开年龄、职业等因素 | 把年龄、职业等因素分开看 |
| 伴随职业比例悬殊 | 职业中的男女比例相差悬殊 |
| 把问题追到…… | 接着追问…… |
| 从制度上赋权了多元文化社会 | 在制度上给多元文化政策撑了腰 |
| 让美国天然抵抗这种倾向 | 美国天生不容易滑向这一步 |

| I mean… / you know… | 我的意思是…… / 你知道…… | 直接删 |

## 引语

- 英文原话又长又散，不要整段放进中文引号。挑出最关键的半句做直接引语，其余转述。
- ❌ 他说："我认为，嗯，你知道，这件事情的问题在于，如果你看一下数据，你会发现它其实并不是人们所想的那样。"
- ✅ 他认为，只要看看数据就会发现，事情"并不是大家想的那样"。

## 标点

- 每千字不超过 4 个破折号。插入说明改用逗号、括号或单独成句。
- 英文原名只在首次出现时括注。
- 中文引号用""；引号里再引用，用''。
